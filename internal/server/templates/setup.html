2. Add the upload step

{{if eq .Workspace.Forge "github"}}

In your GitHub Actions workflow, after the tests:

- run: go test ./... -covermode=atomic -coverprofile=coverage.out
- name: Upload coverage
  run: |
    curl -fsSL https://github.com/gocov/gocov/releases/latest/download/gocov-linux-amd64 -o /usr/local/bin/gocov
    chmod +x /usr/local/bin/gocov
    gocov upload coverage.out
  env:
    GOCOV_TOKEN: ${{"{{"}} secrets.GOCOV_TOKEN {{"}}"}}{{if not .ServerImplicit}}
    GOCOV_SERVER: ${{"{{"}} vars.GOCOV_SERVER {{"}}"}}{{end}}
{{else if eq .Workspace.Forge "gitlab"}}

In your .gitlab-ci.yml — the workflow rules run the job on merge requests and the default branch without duplicate pipelines, and the checksum line pins the binary you download:

workflow:
  rules:
    - if: $CI_PIPELINE_SOURCE == "merge_request_event"
    - if: $CI_COMMIT_BRANCH == $CI_DEFAULT_BRANCH

coverage:
  image: golang:1.23
  script:
    - go test ./... -covermode=atomic -coverprofile=coverage.out
    - curl -fsSLO https://github.com/gocov/gocov/releases/download/v0.9.0/gocov-linux-amd64
    - curl -fsSL https://github.com/gocov/gocov/releases/download/v0.9.0/checksums.txt
      | grep ' gocov-linux-amd64$' | sha256sum -c -
    - chmod +x gocov-linux-amd64
    - ./gocov-linux-amd64 upload coverage.out
{{else}}

The full bitbucket-pipelines.yml — branches and pull-requests share one step so a PR build runs once, not twice:

image: golang:1.23

definitions:
  steps:
    - step: &coverage
        name: Test + upload coverage
        script:
          - go test ./... -covermode=atomic -coverprofile=coverage.out
          - pipe: docker://gocov/upload-pipe:0
            variables:
              FILES: coverage.out
              TOKEN: $GOCOV_TOKEN{{if not .ServerImplicit}}
              SERVER: $GOCOV_SERVER{{end}}

pipelines:
  branches:
    main:
      - step: *coverage
  pull-requests:
    '**':
      - step: *coverage
{{end}}

Commit, branch, repo and PR are auto-detected; other languages can upload lcov, JaCoCo or Cobertura with -format.
